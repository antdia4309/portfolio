# Antonio Diaz | Portfolio

**Live site:** https://antdia4309.github.io/portfolio/

Personal portfolio for Antonio Diaz, Business Analyst for insurance systems and data. It covers 10 years in P&C insurance, Guidewire BillingCenter and PolicyCenter (v7, v9, Cloud), SQL, root cause analysis, and requirements work, plus side projects like an Oracle APEX billing delinquency analytics app.

## Tech stack

- React (Create React App)
- Tailwind CSS
- Lucide icons
- GitHub Pages, deployed with GitHub Actions

## Editing content

All site content (case studies, projects, experience, skills, links) lives in data arrays at the top of `src/App.js`. Edit those and push. The layout code below them doesn't need to change.

Static files live in `public/`:
- `profile.jpg` is the headshot
- `Antonio_Diaz_Resume.pdf` is the resume download

## Run locally

```bash
npm install
npm start
```

Opens at http://localhost:3000/portfolio

## Deploy

Every push to `main` builds and deploys to GitHub Pages through `.github/workflows/deploy.yml`.
